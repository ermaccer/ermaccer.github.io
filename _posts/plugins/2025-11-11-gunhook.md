# Introduction
GUNHook is a plugin for PC version of GUN.

<div class="alert bg-dark">
	GUNHook was only tested with latest Steam and GOG versions!
</div>

<img class="img-fluid mx-auto" alt="menu" src="{% link assets/mods/gun/gunhook/menu.jpg %}">


# Features

| Feature | Description |
| --- | --- |
|Player Modifier| Change player skin. | 
|World Modifier| Create a horse at any time. |
|Speed Modifier| Change game speed. |
|Camera Control| Freeze camera position & rotation. Freely move and rotate camera with keyboard hotkeys.|
|Script| Call script functions. |
|Misc.| Disable HUD. |

# Installation 

Extract **GUNHook.zip** to root folder of GUN.

Archive breakdown:

 - dsound.dll - [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/)
 - GUNHook.asi
 - GUNHook.ini



# Usage

If installed correctly, a notification will appear informing that the plugin was installed
and is ready to use. By default **F1** will open or close in-game menu.
