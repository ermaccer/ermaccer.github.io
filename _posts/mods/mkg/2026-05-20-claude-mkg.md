# Installation

<div class="alert bg-dark">
  These instructions are for GDI dump which is really easy to replace files in.
</div>

1. Download <a href="https://projects.sappharad.com/tools/gdibuilder.html">GDIBuilder</a>
2. Extract the zip archive into a folder
3. Open GDIBuilder, select "Patch a copy"
4. Pick MKG's .GDI file in the "Original GDI" path
5. For "Modified" files pick the extracted folder
6. Set your output path and click "Rebuild GD-ROM"
7. Done
